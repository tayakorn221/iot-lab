# 01-sensor-node

ด่าน 1 — ESP32 อ่าน BME280 ทาง I2C แล้วส่งขึ้น MQTT ทุก 10 วินาที

**ยังไม่มีโค้ด** — เริ่มเมื่อบอร์ดมาถึง (ดู `../../hardware/bom.md`)

ลำดับลงมือ (ทำทีละข้อ ข้อก่อนหน้าต้องเห็นผลบน serial monitor ก่อน):
1. ไฟ LED บนบอร์ดกะพริบ — ยืนยันว่า upload ได้ สายกับไดรเวอร์ถูก
2. อ่าน chip ID ของเซนเซอร์ — ยืนยันว่าเป็น BME280 (`0x60`) ไม่ใช่ BMP280
3. พิมพ์ค่าอุณหภูมิ/ความชื้นออก serial
4. ต่อ Wi-Fi + ซิงก์เวลา NTP
5. ส่ง MQTT ตาม contract + Last Will
6. ทำให้ต่อกลับเองได้เมื่อเน็ตหลุด (เกณฑ์ผ่านด่าน 1)
