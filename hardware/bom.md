# BOM — รายการของที่ต้องซื้อ

ราคาเป็นช่วงประมาณจากร้านออนไลน์ในไทย — **เช็กราคาจริงตอนสั่ง**

## ด่าน 1 (รวมประมาณ 500–800 บาท)

| ของ | จำนวน | ราคาประมาณ/ชิ้น | ทำไมตัวนี้ |
|---|---|---|---|
| ESP32 DevKit (ชิป ESP32-WROOM-32, 38 ขา) | 2 | 150–250 | ตัวที่มีตัวอย่างและคนถามตอบมากที่สุด · ซื้อ 2 เผื่อพังหนึ่งตัว และด่าน 2 ต้องใช้ 2 โหนด |
| BME280 โมดูล I2C | 1 | 100–200 | วัดอุณหภูมิ ความชื้น ความกด ในตัวเดียว ต่อแค่ 4 สาย |
| Breadboard 830 รู | 1 | 40–80 | ต่อวงจรโดยไม่ต้องบัดกรี |
| สายจัมเปอร์ ผู้-ผู้ / ผู้-เมีย | 1 ชุด | 40–80 | |
| สาย USB **ที่ส่งข้อมูลได้** (ตรงหัวของบอร์ด: micro-USB หรือ USB-C) | 1 | 50–100 | |

### กับดักตอนสั่ง
- **BME280 ปลอม = BMP280** (ไม่มีวัดความชื้น) หน้าตาเหมือนกันมาก ร้านถูก ๆ ส่งผิดบ่อย
  ตรวจตอนของมาถึง: เขียนโค้ดอ่าน chip ID — BME280 ได้ `0x60`, BMP280 ได้ `0x58`
- **สาย USB ชาร์จอย่างเดียว** เสียบแล้วเครื่องไม่เห็นบอร์ด — อาการเหมือนบอร์ดเสีย ทั้งที่สายผิด
- ดูชิป USB-to-serial บนบอร์ดว่าเป็น **CP2102** หรือ **CH340** — Windows อาจต้องลงไดรเวอร์ตามรุ่น
