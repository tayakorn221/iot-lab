## 01-sensor-node (ESP32 DevKit ↔ BME280)

| BME280 | ESP32 |
|---|---|
| VCC (บางรุ่นเขียน VIN) | 3V3 |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |
| ADDR, CS (เฉพาะรุ่น 6 ขา) | ไม่ต่อ |

address: รุ่น Waveshare ปล่อย `ADDR` ว่าง = `0x77` · ต่อ `ADDR` ลง GND = `0x76` · เฟิร์มแวร์ลองทั้งสองค่า

ห้ามต่อไฟเลี้ยงโมดูลเข้า 5V ถ้าโมดูลไม่มีวงจรลดแรงดันบนบอร์ด — ดูบนโมดูลก่อน (รุ่น Waveshare มี รับได้ทั้ง 3.3V และ 5V แต่ใช้ 3V3 ไว้ก่อน)
